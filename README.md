### KiCad Notes

`x` to start routing


`v` to create via when routing


`Round Tracks` plugin to round traces (*some traces might require deleting and redoing and re applying the plugin*)


`Edit > Edit Tear Drops > Apply` to create teardrops on vias (*might also require some re doing of tracks and re applying of teardrop*)
